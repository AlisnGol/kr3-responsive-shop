## О проекте

Учебный магазин школьных товаров. Проект выполнен на основе HTML/CSS-сайта из контрольной работы №1. Bootstrap не используется.

Сайт содержит пять страниц:

- `index.html` — главная страница и модальное окно заявки;
- `catalog.html` — каталог товаров и форма фильтров;
- `product.html` — страница рюкзака и таблица характеристик;
- `order.html` — форма заявки;
- `contacts.html` — контакты и учебная форма обратной связи.

Формы демонстрационные: серверная обработка и отправка данных не реализованы. Фильтры каталога представлены интерфейсом без обработки выборки товаров.

## Запуск

Открыть папку проекта в Visual Studio Code и запустить `index.html` через расширение Live Server.

Для проверки Lighthouse сайт необходимо открывать через HTTP, например через локальный адрес Live Server.

## Адаптивные решения

- На всех страницах добавлен viewport.
- Файл `responsive.css` подключён после основных стилей.
- Адаптивные переопределения построены по подходу Mobile First.
- Использованы медиазапросы с основными точками переключения 768 и 1024 px.
- CSS Grid применяется для сетки товаров, каталога, страницы товара и страницы заявки.
- Flexbox используется для навигации, содержимого карточек и кнопок.
- На телефоне товары расположены в одну колонку.
- На планшете товары расположены в две колонки.
- На компьютере главная содержит три колонки товаров, каталог — две с учётом бокового фильтра.
- На планшете группы фильтров расположены в ряд над товарами, на компьютере фильтры находятся сбоку.
- Ссылки навигации переносятся при недостатке места.
- На телефоне изображение товара находится над описанием.
- Поля форм помещаются в контейнеры, кнопки действий на телефоне расположены вертикально.
- Таблица характеристик помещена в отдельный контейнер с горизонтальной прокруткой.
- Подвал находится в обычном потоке страницы и не перекрывает содержимое.
- Кнопки карточек прижаты к нижнему краю и растянуты на всю внутреннюю ширину.
- На странице заявки поля расположены в одну колонку на телефоне и в две колонки от 768 px; комментарий занимает всю строку.

## Изображения

SVG-изображения товаров заменены на PNG.

Для изображений применено ограничение ширины по контейнеру. В карточках используется `object-fit: contain`, чтобы товары отображались целиком без искажения пропорций.

Для рюкзака подготовлены изображения шириной 400 и 800 px. Через `srcset` и `sizes` браузер выбирает подходящий файл с учётом размера изображения на странице и плотности экрана.

## Доступность

- Указан язык страниц `lang="ru"`.
- Используются семантические элементы и последовательная структура заголовков.
- Добавлена ссылка пропуска навигации к основному содержимому.
- Интерактивные элементы имеют видимый фокус.
- У полей форм есть связанные подписи.
- Подсказки формата телефона связаны с полями через `aria-describedby`.
- Изображения товаров имеют текстовые описания `alt`.
- Активные страницы меню обозначены через `aria-current="page"`.
- Таблица содержит заголовочные ячейки с атрибутами `scope`.
- Контейнер таблицы доступен для фокуса с клавиатуры.
- Модальное окно использует элемент `dialog` и метод `showModal()`.
- Проверены открытие окна клавишей Enter, перемещение фокуса клавишей Tab и закрытие через Esc.
- Для сообщения о результате проверки заявки используется `role="status"`.
- Учитывается настройка уменьшения движения `prefers-reduced-motion`.

## Проверка адаптивности

Все пять страниц проверены вручную на ширинах:

- 360 px;
- 430 px;
- 768 px;
- 1024 px;
- 1440 px.

Проверены навигация, карточки, фильтры, изображения, формы, таблица, подвал и модальное окно. Горизонтальная прокрутка всей страницы не обнаружена. Для таблицы допускается прокрутка внутри отдельного контейнера.
